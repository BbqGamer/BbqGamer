# Hi, I'm Adam

I'm a software engineer with an MSc in Artificial Intelligence. I build production AI systems, developer tools, and enterprise integrations, with a focus on making agentic applications reliable enough to use in real workflows.

My recent work spans document-processing agents, LLM evaluation and observability, MCP integrations, multilingual speech analytics, and backend services built with Python, Go, TypeScript, and Kubernetes.
